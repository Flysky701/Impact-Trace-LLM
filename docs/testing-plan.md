# 测试与覆盖率方案

日期：2026-10-02。状态：用户确认课程仅规定覆盖率 ≥75%；当前仓库浏览骨架已通过后端 15 项、前端 17 项和浏览器流程 1 项测试。后端行覆盖率 99.06%、前端 99.02%；仅针对已实现代码，未实现功能不在本次结果中。

## 使用范围

本方案列出阶段与最终验收标准；日常开发的测试强度和审批沿用全局规则。局部改动优先选相关用例，文档/文案小改不运行全套矩阵；只有明确跨模块影响或正式验收时才扩大范围。课程要求的前后端行覆盖率分别 ≥75% 不变，不作为每次编辑后的重复统计任务。

## 统计口径

- 后端自有业务源码 `backend/app/**/*.py` 的行覆盖率 ≥75%。采集整个源码目录，包括尚未被测试导入的文件。
- 前端自有业务源码 `frontend/src/**/*.{ts,vue}` 的行覆盖率单独 ≥75%。使用显式 include，避免仅统计测试加载的文件。
- 同时报告分支覆盖率，用它检查异常路径；初版不把分支值与行值混为同一指标。后端门槛从覆盖报告的行计数单独判断，启用分支统计后不直接把混合总数称为行覆盖率。
- 前后端分别达标，不用后端较高的覆盖率抵消前端不足；报告列出可执行行、已覆盖行及比例。
- 排除测试本身、第三方依赖、构建产物、纯类型声明和演示仓库；工具脚本不属于应用覆盖分母，但须保留复现验证。配置中写明排除规则，不能排除认证、存储、模型适配等难测业务代码。
- 最终保存机器可读及 HTML 报告、源码提交 SHA、运行命令和失败用例；依赖安装后落实具体测试配置与门槛命令。

## 关键验证矩阵

| 范围 | 验证场景 | 检查重点 |
| --- | --- | --- |
| 登录与角色 | 正确/错误密码、过期会话、未登录、角色越权、无项目权限 | 服务端拒绝未授权操作，不只隐藏按钮；凭据不出现在日志 |
| Git 与快照 | 正常 SHA、无效引用、无变化、路径带空格、读取失败 | 版本固化正确，不改动用户工作区，不执行仓库脚本 |
| 解析 | 普通函数、类方法、导入别名、嵌套作用域、同名符号、语法错误 | 源码范围与限定名称正确；未知调用不会被伪装成确定边 |
| 变更与图谱 | 新增、删除、重命名候选、两个版本同名实体 | 删除依赖查旧图，新增查新图，快照互不污染 |
| 传播 | 一跳/多跳、多调用者、循环、深度/数量截断 | 反向方向正确、不会无限遍历；保留证据及截断提示 |
| 模型适配 | 正常响应、超时、额度不足、错误引用、认证过期 | 静态结果保留；无效证据被标识；不会无限重试或重复收费 |
| 报告与审核 | 填写/更新风险、手动测试结果、重开历史报告 | 关联正确任务，记录操作者与时间；查看历史不触发新模型调用 |
| 前端交互 | 图节点选中、版本切换、表单校验、错误与部分完成状态 | 展示与后端状态一致，源码指向正确提交，角色操作正确 |

模型单元测试模拟 HTTP 和 OAuth 响应，测试网络不依赖真实账号。首次真实连通与报告质量检查另作人工验收，不能用模拟结果代替。

## 完整演示验收

2026-11-06 新增设计的定向验收：前后流程分别绑定正确 SHA；旧图标红修改与删除，新增只作旧图注释；节点和边映射有歧义时提示；原图、流程、diff 与证据定位一致。检查覆盖率时分别验证未导入、无可执行变更行、部分范围与版本不匹配，不能将这些状态显示为 0% 或测试通过。PR 模式接入后验证实际 merge-base 与旧图/diff 一致。上述正式能力尚未实现，不属于已有通过记录。

1. 开发者导入 TinyDB，固定版本并查看模块及源码。
2. 分析样例 A 或 B，核对变化实体和至少一条已人工核对的影响路径。
3. 对一个可追溯的 AI 修改案例填写任务及已有操作记录；记录缺失的阶段，不补造过程。
4. 在用户明确批准真实调用及费用范围后，生成一次真实模型解释，抽查证据引用并记录模型及调用状态；批准前使用模拟结果验证流程，不重复调用已验证且未受影响的付费步骤。
5. 审核者确认风险并填写测试结果，再重新打开历史记录。
6. 演示模型不可用时的基础报告和越权请求拒绝。
7. 自动化测试及覆盖率门槛通过，补充小型自建样例检查新增、删除、循环和无变化。

精确率和召回率不以整个开源仓库为分母。若报告这些指标，必须提供人工标注集合与未解析范围；本阶段样例检查只说明选定场景的表现。

工具依据：[FastAPI 测试](https://fastapi.tiangolo.com/tutorial/testing/)、[pytest-cov 配置](https://pytest-cov.readthedocs.io/en/latest/config.html)、[Coverage.py 配置](https://coverage.readthedocs.io/en/latest/config.html)、[Vitest 覆盖率](https://vitest.dev/guide/coverage.html)。
