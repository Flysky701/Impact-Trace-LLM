# 架构决策记录（ADR）

用于保存重要技术决定、依据与取舍。

| 编号 | 决策 | 状态 |
| --- | --- | --- |
| [0001](0001-mvp-technology.md) | 单人课程原型的技术基线 | 已接受为实施基线，集成与模型连接待验证 |

## 使用方式

复制 [决策模板](0000-template.md)，命名为 `0001-简短主题.md`，后续编号递增。提议阶段保留“提议”状态；评审确定后再改为“已接受”。方案变化时新增决策并注明替代关系，保留旧记录。

适合记录的内容包括首批分析语言、解析方案、图谱存储、LLM 接入、版本隔离及部署方式。
