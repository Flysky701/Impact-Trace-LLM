## 产品定位与取舍

产品定位更新为：**面向团队的 Git 代码审阅工作台，通过前后流程、架构上下文和源码证据解释一次变更。** 课程基线保留 Python/TinyDB；当前用户实验优先 Kotlin/LimingjieDesktop。企业认证、私有仓库和部署能力尚未实现。

核心价值来自版本、差异、依赖路径与源码证据的对应关系。LLM 负责解释已有证据、提出检查建议；静态分析结果在模型不可用时仍应可读。关系图展示整体结构，结构树补足定义，影响清单支持逐项核对。

首版保持 10 项核心功能、两类角色、本机 Web、Python/TinyDB，以及前后端业务源码行覆盖率分别 ≥75% 的课程约束。扩展优先复用这些数据与页面，避免在核心流程未完成时增加独立子系统。
