状态：交付演示的计划，尚未全部实现。可点击原型只展示页面与交互，不作为算法、模型或测试效果的证明。

## 主案例与演示目的

主案例采用 TinyDB 历史修复 B：更新或删除时跳过不存在的文档 ID。它能展示实际改动、候选调用关系、需要复核的行为和双角色审核。完整历史核对见[样例验证](sample-validation.md)。

- 基准：`8a2dc204c265c07ce8506a3599a28e720b6dcdd7`
- 目标：`76d21d26c682e1ca6ca25bd8e81edf9f609ac52f`
- 类型：历史提交分析；不声称作者使用了 AI。
- 重点：Table.update、remove、upsert 均发生改动；upsert 调用 update，因此同一个实体可以既被改动，又处在影响路径上。
- 已有测试线索：`test_update_ids_missing`、`test_update_ids_mixed`、`test_remove_ids_missing`、`test_remove_ids_mixed`、`test_doc_id_missing_consistency`。它们是已有测试名称，尚未在此运行，不能提前标为通过。

## 建议的 8～10 分钟主流程

| 步骤 | 页面与动作 | 应讲清的内容 | 对应验收 |
| --- | --- | --- | --- |
| 1（1 分钟） | 开发者登录并进入 TinyDB | 本地仓库、固定版本、历史长度；用户只访问分配项目 | UC-01 |
| 2（1 分钟） | 概览中选择 table 模块并打开源码 | 平台帮助理解项目，结构来自代码，职责解释有依据及边界 | UC-02 |
| 3（1 分钟） | 新建历史分析，填目的并选择固定 SHA | 明确比较哪两个不可变版本；可选择先做基础分析 | UC-03 |
| 4（2 分钟） | 打开整体模块图，查看 table 的改动和依赖影响；展开 Table，选择 update/upsert；切换结构树和清单 | 全貌中的改动位置；模块级与函数级候选的区别；路径、源码版本及解析边界 | UC-03 |
| 5（1 分钟） | 查看解释、局限和测试建议 | 解释引用证据；动态转发未解析；已有测试与新增建议分开 | UC-03、UC-06 |
| 6（1～2 分钟） | 审核者登录，提交意见与真实测试记录 | 意见、操作者与报告绑定；平台没有自动执行样例测试；未运行就选未执行 | UC-05 |
| 7（1 分钟） | 返回历史，重开报告；展示模型失败状态 | 历史不重新调用模型；解释失败仍可核对基础结果 | UC-05、UC-06 |

真实演示前应先生成并保存报告，现场可重开已有结果；如现场重新分析，则显示真实运行状态。缓存结果明确标为历史结果。

## 补充案例：真实 AI 修改记录

历史主案例不能单独验收 AI 记录和间接影响，需准备一个受控的真实任务：

1. 在单独的 TinyDB 工作副本选定基准 SHA，给 AI 一个范围有限的实际修改任务；任务内容待人工核对代码后选定。
2. 保存用户要求及工具实际产生的操作记录，人工检查 diff，再固定目标提交。
3. 整理至少一条可从代码证明的直接关系及一条两级间接路径；若该任务没有间接路径，另用小型自建回归样例验证，不伪造主案例的影响范围。
4. 在平台选择“AI 修改记录”，输入真实要求、记录来源、前后提交，解释任务与改动的对应关系。
5. 未记录的阶段如实标注。模型事后写的报告不能回填成原始工作过程。

当前尚未执行这个任务；产品原型允许体验表单，但不会创建真实 Git 提交。

## 实现后必须准备的验证材料

| 材料 | 最少内容 | 当前状态 |
| --- | --- | --- |
| 固定版本与差异 | 完整 SHA、文件清单、方法变更、来源行号 | 提交及部分关系已核对，完整标注待整理 |
| 人工影响清单 | 已确认关系、候选、未解析点、预期路径 | 待完成；不能用模型输出充当标准答案 |
| AI 任务记录 | 真实要求、可选操作记录、两个实际提交 | 待准备 |
| 审核及测试 | 真实审核意见；实际执行步骤/命令、结果，或未执行原因 | 待正式实现后填写 |
| 平台测试报告 | 当前全部自有源码、前后端分别行覆盖率 ≥75%、关键异常用例 | 骨架已有报告，新增业务后须重新统计 |
| 失败演示 | 模型失败、解析缺口、无效 SHA、同版本无变更 | 原型预览部分场景，正式行为待验证 |

## 原型的体验路径

打开 `docs/prototype/index.html` → 项目概览 → 新建分析 → 生成示例报告 → 点击变更实体/路径 → 查看任务记录 → 切换“审核者” → 填意见并保存 → 历史记录重新打开。顶部可切换模型不可用、部分解析和无变更情形。

v0.2 报告体验：模块总览显示全部 10 个业务 Python 文件；选 database 或 __init__ 查看候选传播路径；展开 Table 看函数子图；切换结构树搜索定义，再用影响清单逐项核对。连线来自目标快照的静态语法证据，不能当作运行时完整路径。

该路径只验证交互。正式功能、模型效果与课程覆盖率仍以真实应用的验收结果为准。
