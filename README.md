# Impact-Trace-LLM

**基于 LLM 与代码知识图谱的软件变更影响平台**

项目处于初始化与方案论证阶段。目标是结合代码结构、依赖关系和大语言模型，帮助开发者理解一次代码变更可能影响哪些模块、调用方与测试，并给出可追溯的分析依据。

当前仓库仅包含项目规划与协作基础配置，尚未实现可运行系统，也未确定编程语言、框架、数据库或模型供应商。

GitHub 公开仓库：[Flysky701/Impact-Trace-LLM](https://github.com/Flysky701/Impact-Trace-LLM)。默认分支：`main`。

## 预期使用流程

1. 接入一个代码仓库，选择基准提交与目标提交。
2. 解析代码与差异，将变更定位到文件、类、函数等实体。
3. 根据依赖关系生成潜在影响集合和传播路径。
4. 由 LLM 基于代码片段与关系证据解释影响，标明推测与分析边界。
5. 展示影响清单、路径、测试建议及对应源码位置，供人工复核。

## 本地开始

打开本仓库，先阅读项目定位与需求草案。当前仅需 Git 和文本编辑器，无需安装业务运行环境。后续确定技术栈后再补充源码目录、依赖管理、运行命令与自动化测试。

在其他目录或机器获取项目：

```sh
git clone https://github.com/Flysky701/Impact-Trace-LLM.git
cd Impact-Trace-LLM
```
