# Impact-Trace-LLM

**基于 LLM 与代码知识图谱的软件变更影响平台**

项目源于课程作业，关注阅读项目时难以理解整体架构、难以判断 AI 修改代码的影响这两个问题。目标是结合代码知识图谱与大语言模型，帮助使用者理解项目结构、回顾 AI 修改过程，并获得有源码依据的变更解释。

计划由 1 人在一个月以内完成可演示、功能基本可用的 Web 原型，具体工期可浮动。首版范围已确定为“项目结构浏览 → 记录修改任务 → 对比修改前后 → 解释潜在影响 → 审核与测试记录”。采用开发者和审核者／测试负责人两个角色，按 10 个核心功能组织，前后端自有业务源码行覆盖率分别须达到 ≥75%。首版分析 Python，以具有完整 Git 历史的 TinyDB 为主样例；多语言作为扩展方向。

当前已有可运行的本机 Web 骨架：登录与双角色权限、项目接入、Git 历史和固定版本源码查看。Python/FastAPI、Vue/TypeScript 与 SQLite/SQLAlchemy 已完成集成，依赖已锁定。Cytoscape.js 图谱、正式影响分析和模型报告尚未接入；模型候选为 DeepSeek API 或 OpenAI OAuth。

2026-11-06 产品方向调整为 **Git 代码审阅工作台**：以修改前后流程对照、旧图改动标红、分层架构图和源码依据为核心；测试与覆盖率作为审阅证据，问答作为上下文辅助。保留首版 10 项功能，按有限 Python 范围先打通真实流程。详见[产品设计 v0.3](docs/product-design.md)、[功能优先级](docs/roadmap.md)与[源码现状](docs/project-status.md)。

## 当前可运行版本

新增 **LimingjieDesktop 离线图谱 Demo**：从本机 Git 和工作区自动提取 Kotlin 模块依赖、函数活动、变更标记与 Room 数据库图，并提供源码定位和改进线索。场景层为有证据的人工分组，调用目标仍是静态候选；没有接入 DeepSeek 或执行目标项目。运行方式见[离线代码图谱 Demo](docs/local-development.md#离线代码图谱-demo)。产物保存在被 Git 忽略的 `reports/generated/`，不与公开源码一起提交。

独立的[仓库审阅原型 v0.4](docs/prototype/review.html)展示“代码 / 架构 / 比较 / 检查 / 审阅记录”，包含前后流程、旧图标红、真实 diff，以及新增的“活动图”：从整体场景展开模块活动，再定位函数与代码。架构页提供模块依赖、调用关系与 TinyDB 逻辑数据模型。使用固定提交，活动与流程为人工整理，问答为人工示例，覆盖率未导入，审核刷新重置；不代表正式后端已具备自动生成能力。

[旧版原型 v0.2](docs/prototype/index.html)保留用于查看早期“项目概览 → 新建分析 → 报告 → 审核 → 历史”的页面安排。两版均不连接模型。

2026-10-04 更新至产品原型 v0.2：以整体代码关系图为主要视图，在图中标注改动及影响候选；配合结构树和影响清单查看完整范围。关系数据来自 TinyDB 固定快照的静态提取，仍不是正式分析引擎。

- 开发者创建项目并指定审核者，其他用户无法读取未分配的项目。
- 从允许的本地目录接入 Git 仓库，分页浏览提交并打开该版本源码。

- 2026-10-02 的测试记录：后端 15 项、前端 17 项、浏览器流程 1 项通过；当时已实现代码的行覆盖率后端 99.06%、前端 99.02%。这些指标不代表尚未实现的分析模块，本次现状整理未重新运行测试。

安装后运行 `./scripts/start-local.ps1`，访问 <http://127.0.0.1:8765>。首次启动生成两个随机密码账号，账号文件位于本机 `data/local/demo-credentials.txt`。完整步骤见[本机启动与开发](docs/local-development.md)。

## 预期使用流程

1. 接入代码仓库，浏览模块、文件和主要依赖，查看附源码依据的结构说明。
2. 记录一次 AI 修改任务的用户要求与修改前后提交；已有对话或操作记录可人工附加。
3. 解析差异，定位变更实体，生成潜在影响集合和传播路径。
4. 由 LLM 基于代码片段与关系证据解释实际改动、可能影响和需复核的问题。
5. 在报告中查看任务要求、实际改动、源码定位及建议检查项。
6. 审核者确认风险、添加意见、手动记录测试结果；两类角色均可查看历史分析和审核记录。

在其他目录或机器获取项目：

```sh
git clone https://github.com/Flysky701/Impact-Trace-LLM.git
cd Impact-Trace-LLM
```
